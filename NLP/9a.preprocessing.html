Chapter 9: Text Preprocessing in Natural Language Processing

9.1 Introduction

When humans read a paragraph, they naturally understand context, structure, and meaning. In contrast, computers lack this innate ability. To make text machine-readable, it must be cleaned, structured, and transformed into numerical form. This process is known as text preprocessing and forms the first and most critical step in any Natural Language Processing (NLP) pipeline. Effective preprocessing helps reduce noise, improve model accuracy, and extract meaningful patterns from text data.

This chapter introduces foundational preprocessing techniques that are essential for NLP tasks such as text classification, sentiment analysis, and topic modeling.

9.2 Why Preprocess Text?

Consider developing a spam detection system. Emails vary in style and content:

  • Some are in all capital letters: "BUY NOW!!!"
  • Some contain typographical errors: "Fr33 monney just for yu!"
  • Others include inconsistent punctuation or HTML tags

Feeding such unprocessed data into a model increases complexity and reduces performance. Models may treat "Buy" and "buy" as different words or distinguish between "money" and "money." (with punctuation). Preprocessing standardizes these differences so the model can focus on meaningful patterns.

9.3 Lowercasing

Lowercasing is one of the simplest yet most effective text preprocessing techniques. It converts all uppercase letters in the text to lowercase.

Why Lowercase?

By converting all text to lowercase, we ensure that words like "Apple," "apple," and "APPLE" are treated as the same word. This significantly reduces the vocabulary size and helps in standardizing the text, preventing the model from learning different representations for the same word due to case variations. While generally beneficial, there are niche cases (e.g., Named Entity Recognition) where preserving case might be important.

Code Example

text = "Natural Language Processing Is AMAZING!"
lower_text = text.lower()
print(lower_text)
# Output: "natural language processing is amazing!"

9.4 Tokenization

Tokenization involves splitting text into smaller components called tokens. Tokens may represent words, sentences, or subword units. For example, the sentence:

"I can't believe it's not butter!"

might be tokenized as:

["I", "ca", "n't", "believe", "it", "'s", "not", "butter", "!"]

Real-World Analogy

Tokenization is similar to chopping vegetables before cooking. Just as ingredients need to be properly sized for a meal, models need properly segmented text tokens for analysis.

Code Example (NLTK)

from nltk.tokenize import word_tokenize, sent_tokenize

text = "Natural Language Processing is amazing. Let's explore it!"
sentences = sent_tokenize(text)
words = word_tokenize(text)

9.5 Removing Punctuation

Punctuation helps humans understand text, but for many NLP models, it adds little value. Removing it simplifies the vocabulary.

Why Remove It?

Punctuation can inflate the number of unique tokens. For instance, "hello," and "hello" may be treated as different tokens.

Code Example

import string

text = "Hello, world! How are you?"
words = word_tokenize(text) # Assuming text is already lowercased and tokenized
words_no_punct = [w for w in words if w not in string.punctuation]
print(words_no_punct)
# Output: ['Hello', 'world', 'How', 'are', 'you'] (if from original text)
# Output: ['hello', 'world', 'how', 'are', 'you'] (if from lowercased text)

9.6 Removing Stop Words

Stop words are common words like "the," "is," and "in" that typically do not carry important meaning.

Why Remove Them?

They occur frequently across all documents and do not help distinguish between topics or sentiments. However, care must be taken—words like "not" can be critical in sentiment analysis.

Code Example

from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

text = "The quick brown fox jumps over the lazy dog."
tokens = word_tokenize(text.lower()) # Lowercase first
stop_words = set(stopwords.words('english'))
filtered_words = [w for w in tokens if w not in stop_words]
print(filtered_words)
# Output: ['quick', 'brown', 'fox', 'jumps', 'lazy', 'dog', '.']

9.7 Stemming

Stemming reduces words to their root form by stripping suffixes. Examples:

  • "playing" → "play"
  • "flies" → "fli"

Stemming is fast but may not produce dictionary words.

Caveat

Stemming can result in non-words like "amaz" instead of "amaze."

Code Example

from nltk.stem import PorterStemmer
from nltk.tokenize import word_tokenize

text = "running runs runner walked"
tokens = word_tokenize(text.lower())
stemmer = PorterStemmer()
stemmed_words = [stemmer.stem(w) for w in tokens]
print(stemmed_words)
# Output: ['run', 'run', 'runner', 'walk']

9.8 Lemmatization

Lemmatization is a more sophisticated approach that considers word context and part of speech. It returns proper dictionary root forms.

Example

  • "better" → "good" (lemma)
  • "better" → "better" (stem)

When to Prefer Lemmatization

Use it when:

  • You need linguistically valid words
  • Performing semantic or interpretable analysis

Code Example

import spacy

# Make sure to download the English model: python -m spacy download en_core_web_sm
nlp = spacy.load("en_core_web_sm")

text = "The quick brown foxes are running, and they have better chances."
doc = nlp(text.lower()) # Lowercase first
lemmatized_words = [token.lemma_ for token in doc]
print(lemmatized_words)
# Output: ['the', 'quick', 'brown', 'fox', 'be', 'run', ',', 'and', 'they', 'have', 'good', 'chance', '.']

9.9 Removing Numbers

Numbers may be useful in some domains (e.g., prices, dates) but irrelevant in others (e.g., topic modeling).

When to Keep Numbers

  • When numbers have semantic or predictive importance

Code Example

import re

words_with_numbers = ['the', 'meeting', 'is', 'on', '2023', 'at', '5pm', 'item-42']
words_no_numbers = [w for w in words_with_numbers if not w.isdigit() and not re.match(r'.*\d.*', w)]
print(words_no_numbers)
# Output: ['the', 'meeting', 'is', 'on', 'at']

9.10 Whitespace Normalization

Text often includes inconsistent whitespace from user input, web scraping, or OCR. Removing extra spaces improves consistency.

Code Example

text = "  This   is an   example with    irregular   spaces. "
cleaned_text = " ".join(text.split())

9.11 Summary: When to Use Each Technique

Technique Purpose Notes
Lowercasing Standardizes text, reduces vocabulary size Crucial for consistency; may lose info for NER
Tokenization Splits text into components Fundamental for all NLP tasks
Punctuation Removal Reduces noise May affect emotional tone or structure
Stop Word Removal Removes frequent non-informative words Avoid removing sentiment words like "not"
Stemming Normalizes to base form quickly May reduce words too aggressively; not dictionary words
Lemmatization Refines to dictionary root More accurate, context-aware; generally preferred over stemming
Number Removal Reduces irrelevant digits Keep numbers if semantically meaningful
Whitespace Cleaning Enhances text consistency Useful for text parsing and general tidiness

9.12 Conclusion

Text preprocessing transforms unstructured text into clean, structured, and meaningful representations suitable for modeling. By thoughtfully applying these techniques, practitioners can significantly improve NLP performance. Each method serves a purpose, and understanding their roles allows for building robust, efficient, and accurate NLP pipelines. The practical example demonstrates how these steps are chained together to prepare raw text for downstream NLP tasks.

Practical Application: Preprocessing a Real Data

Let's apply these techniques to a sample text data, simulating a small real-world dataset. For simplicity, we'll use a list of sentences as our "dataset."

Setup

First, ensure you have the necessary NLTK data and spaCy model downloaded:

Example

import nltk
import spacy
import string
import re

nltk.download('punkt')
nltk.download('stopwords')
nltk.download('wordnet') # For Lemmatization (NLTK's WordNetLemmatizer)

#For spaCy, run: python -m spacy download en_core_web_sm

nlp = spacy.load("en_core_web_sm")
# A small, simulated dataset
documents = [
    "I love Natural Language Processing! It's truly amazing and I'm learning a lot.",
    "The quick brown fox jumps over the lazy dog 123 times a day.",
    "BUY NOW!!! This offer is too good to miss. (Limited time)",
    "Are you still running the old version? Better update to the new one."
]

processed_documents = []

for doc in documents:
    print(f"\nOriginal: {doc}")

    # 1. Lowercasing
    text_lower = doc.lower()
    print(f"Lowercased: {text_lower}")

    # 2. Tokenization
    tokens = word_tokenize(text_lower)
    print(f"Tokenized: {tokens}")

    # 3. Removing Punctuation
    tokens_no_punct = [word for word in tokens if word not in string.punctuation]
    print(f"No Punctuation: {tokens_no_punct}")

    # 4. Removing Numbers (purely numeric or containing digits)
    tokens_no_numbers = [word for word in tokens_no_punct if not word.isdigit() and not re.match(r'.*\d.*', word)]
    print(f"No Numbers: {tokens_no_numbers}")

    # 5. Removing Stop Words
    stop_words = set(stopwords.words('english'))
    tokens_no_stopwords = [word for word in tokens_no_numbers if word not in stop_words]
    print(f"No Stopwords: {tokens_no_stopwords}")

    # 6. Lemmatization (using spaCy for better accuracy)
    # Join tokens back to a string for spaCy processing
    text_for_lemmatization = " ".join(tokens_no_stopwords)
    spacy_doc = nlp(text_for_lemmatization)
    lemmatized_tokens = [token.lemma_ for token in spacy_doc]
    print(f"Lemmatized: {lemmatized_tokens}")

    # 7. Whitespace Normalization (applied after joining for better effect, or on initial raw text)
    # In this pipeline, it's implicitly handled by tokenization and rejoining.
    # If we had kept original text with irregular spaces and then applied lowercasing,
    # it would be more explicit. Let's do a final join and normalize.
    final_cleaned_text = " ".join(lemmatized_tokens)
    final_cleaned_text = " ".join(final_cleaned_text.split()) # Redundant here, but for explicit whitespace clean
    print(f"Final Cleaned Text: {final_cleaned_text}")

    processed_documents.append(final_cleaned_text)

print("\n--- All Documents Processed ---")
for i, doc in enumerate(processed_documents):
    print(f"Document {i+1}: {doc}")
